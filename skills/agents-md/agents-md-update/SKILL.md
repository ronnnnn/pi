# AGENTS.md 更新ワークフロー

既存の AGENTS.md ファイルを精査し、最適化する。

## 重要な原則

1. **冗長コンテンツを削除** - agent が既知の一般的なベストプラクティスは含めない
2. **必須セクションを確認** - 日本語スタイリング、コード参照、技術調査優先順位
3. **肥大化を防止** - 目標 500-1,500 words、最大 3,000 words
4. **ユーザー承認を得てから適用**

## 作業開始前の準備

**必須:** 作業開始前に `todo({ action: "list" })` で残存タスクを確認し、存在する場合は `todo({ action: "clear" })` で全て削除する。その後、`todo` tool で以下のステップをタスクとして登録する:

```
todo({ action: "add", text: "AGENTS.md の読み込み (ファイルを読み込み、文字数を計測)" })
todo({ action: "add", text: "必須セクションの確認 (日本語スタイリング、コード参照、技術調査優先順位を確認)" })
todo({ action: "add", text: "冗長性の検出 (agent が既知の一般的な内容を特定)" })
todo({ action: "add", text: "最適化提案の作成 (削除・統合・追加の提案を作成)" })
todo({ action: "add", text: "ユーザー承認 (変更内容の承認を求める)" })
todo({ action: "add", text: "変更の適用 (承認後に変更を適用)" })
todo({ action: "add", text: "完了報告 (更新結果を報告)" })
```

各ステップの完了時に `todo({ action: "toggle", id: <id> })` で完了済みに更新する。

## 実行手順

### 1. 対象ファイルの決定

- 引数 (パス) が指定された場合: `<path>/AGENTS.md` または `<path>`
- 引数がない場合: 現在のディレクトリの `AGENTS.md`

### 2. AGENTS.md の読み込み

```bash
# ファイルの存在確認 (CLAUDE.md 併存コピーの有無も確認)
ls -la AGENTS.md CLAUDE.md 2>/dev/null
```

`read` tool で内容を読み込み、文字数を計測。

### 3. 必須セクションの確認

スタイルガイド (`../agents-md-style/SKILL.md`) を `read` で読み込み、以下が含まれているか確認し、不足があれば追加提案:

- 日本語使用時のスタイリング
- コード参照 (LSP 使用)
- 技術調査優先順位

### 4. 冗長性の検出

以下に該当する内容を特定:

| カテゴリ                             | 判断基準         |
| ------------------------------------ | ---------------- |
| 一般的なベストプラクティス           | agent は既知     |
| 標準的なコーディング規約             | agent は既知     |
| 言語・フレームワークの基本的な使い方 | agent は既知     |
| IDE やエディタの使い方               | agent は既知     |
| 一般的な Git ワークフロー            | agent は既知     |
| 繰り返し・重複する内容               | 1 箇所に統合可能 |
| 使用されていない古い情報             | 削除対象         |

### 5. 最適化提案の作成

削除・統合すべき内容をリストアップ:

- 各項目について削除理由を説明
- 統合可能な項目を提案
- 追加すべき必須セクションを提示

### 6. ユーザー承認

変更内容を表示し、`question` tool で承認を得る:

```
## 最適化提案

### 削除対象
- [項目1]: [理由]
- [項目2]: [理由]

### 追加対象
- [必須セクション]: [不足している場合]

### 変更後の文字数
- 現在: X words
- 変更後: Y words (Z% 削減)

この変更を適用しますか？
```

### 7. 変更の適用

承認後、`edit` tool で変更を適用。

**CLAUDE.md 併存コピーとの同期:** プロジェクトに CLAUDE.md が AGENTS.md の実ファイルコピーとして併存する場合は、適用後にバイト単位で一致するよう同期する (プロジェクトに同期タスクがあればそれを使用)。

### 8. 完了報告

```
## AGENTS.md 更新完了

- **ファイル:** <path>
- **変更前:** X words
- **変更後:** Y words
- **削減率:** Z%
```

## 保持対象

以下は削除しない:

- プロジェクト固有のワークフロー
- カスタムスクリプトやツールの使い方
- ドメイン固有の規約
- チーム固有のルール
- アーキテクチャ決定事項

## エラーハンドリング

### AGENTS.md が存在しない場合

```
AGENTS.md が見つかりません。/skill:agents-md-init で新規作成してください。
```

### 変更が不要な場合

```
AGENTS.md は既に最適化されています。変更は不要です。
```
